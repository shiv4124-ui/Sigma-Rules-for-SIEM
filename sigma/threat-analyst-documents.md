# Documents a Threat Analyst Creates and Maintains

| Document | Purpose |
|---|---|
| Threat intelligence reports | Strategic, operational and tactical intel for different audiences |
| IOC lists | IPs, domains, URLs, hashes with confidence, source and expiry — see [ioc-types.md](ioc-types.md) |
| Threat actor profiles | TTPs mapped to MITRE ATT&CK, targeting, tooling |
| Threat models | e.g. STRIDE for systems and applications |
| Incident / investigation reports | Timeline, impact, root cause, recommendations |
| Playbooks and runbooks | Phishing, ransomware, credential theft response steps |
| Risk assessments | Vulnerability prioritisation by exploitability and business impact |
| Priority Intelligence Requirements (PIRs) | The questions leadership needs answered |
| Weekly / monthly threat briefings | Management summaries — see [`latest-attacks/`](../latest-attacks/) |
| Detection rules | Sigma rules under [`rules/`](../rules/) |
